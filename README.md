# Banking Management System

An offline Banking Management System developed as a college project using Python.

## Features

- User account management
- Banking transactions
- Deposit and withdrawal functionality
- Account balance management
- Rule-based AI chatbot for banking-related assistance
- Simulated offline stock market
- Stock buying and selling simulation

## AI Chatbot

The project includes a rule-based chatbot that provides responses to common banking and stock-market related questions.

The chatbot works offline and does not require an external AI API.

## Stock Market Module

The stock market section is a simulated environment using dummy/offline market data.

It is intended for educational purposes and does not connect to real financial markets.

## Technologies Used

- Python
- Tkinter
- SQLite
- Rule-based chatbot logic

## Project Structure

- `app.py` — Main application
- `database.py` — Database-related functionality
- `chatbot.py` — Rule-based chatbot
- `market.py` — Stock market logic
- `stock_page.py` — Stock market interface
- `assistant_page.py` — AI assistant interface
- `ui.py` — User interface components
- `test_db.py` — Database testing
## Note

This project is an educational/college project. It uses simulated financial data and is not intended for real banking or investment use.
